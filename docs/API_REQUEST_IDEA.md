# Project idea for API access

GoldenEpics Qloo Creative Agent turns a small business’s rough campaign brief into a practical advertising plan. Users describe their product, audience and goal, then compare creative directions, choose a concept and export ad copy, a video script and a production brief. Qloo’s API adds cultural context: it connects audience interests to relevant music, films, books and brands, helping our workflow choose more specific themes and storytelling references. Each direction shows which insights informed it and how they changed the original product pitch. Our goal is to help small teams move from “what should we advertise?” to a clear, evidence-informed campaign they can produce.

## Scope accuracy

The product creates written creative plans. It does not claim to measure campaign performance or generate finished media. Its current planner is deterministic, driven by returned entity metadata; the API is accessed through the supported Qloo harness. Live verification awaits the event key.
